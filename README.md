# API REST - Proyecto Spring Boot (Cheaf App)

Backend desarrollado en Java con Spring Boot para la gestión de ofertas de alimentos y autenticación de usuarios.

## Estructura de Controllers
1. **AuthController (`/api/auth`)**: Manejo de estado de sesión y perfil de usuario.
2. **OfertaController (`/api/ofertas`)**: Gestión de lista de platillos y ofertas destacadas.

## Requisitos de Ejecución
- Java 17 o superior
- Maven

## Instrucciones para ejecutar
1. Clonar el repositorio.
2. Ejecutar en la terminal desde la raíz del proyecto:
   ```bash
   mvn spring-boot:run
